# Product

## Primary user

A technically competent user or small team that wants useful local AI without needing to operate a full ML platform.

## MVP promise

Install CyberHIVE on a headless Linux host, enroll at least one NVIDIA worker, deploy a compatible local model, expose it through a stable API/web UI, inspect health/usage and recover safely from a failed update.

## Product constraints

- setup must remain understandable without Kubernetes knowledge
- offline/local operation must remain viable
- cloud integration must be additive, not required
- dangerous operations must be explicit and auditable
- low/medium-end consumer GPUs remain first-class targets
